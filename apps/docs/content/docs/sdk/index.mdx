# SDK

The `@athreei/sdk` enables any website to become an MCP server. When users visit your site with athreei, your custom tools become available to their AI assistant.

## Why Integrate?

Think of it like OpenAI's ChatGPT App Store, but for any website:

```
┌─────────────────────────────────────────────────────────────┐
│                      User's AI App                          │
│  "Search for products under $50 and add the best to cart"   │
└───────────────────────────────┬─────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────┐
│                      athreei Gateway                        │
│              (routes request to your website)               │
└───────────────────────────────┬─────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────┐
│                     Your Website                            │
│   ┌─────────────┐  ┌─────────────┐  ┌─────────────────┐     │
│   │search_prods │  │ add_to_cart │  │ checkout        │     │
│   └─────────────┘  └─────────────┘  └─────────────────┘     │
│              (your custom tools via SDK)                    │
└─────────────────────────────────────────────────────────────┘
```

**Benefits:**
- Users can interact with your site via natural language
- Your business logic stays on your servers
- You control what AI can and can't do
- Works with any AI app that supports MCP

## Installation

```bash
npm install @athreei/sdk
```

Or via CDN:

```html
<script type="module">
  import { athreei } from 'https://unpkg.com/@athreei/sdk@latest/dist/index.js'
</script>
```

## Quick Start

```typescript
import { athreei } from '@athreei/sdk'

// Wait for athreei to be ready
athreei.onReady((info) => {
  console.log('athreei connected:', info.version)
})

// Register a custom tool
athreei.registerTool({
  name: 'search_products',
  description: 'Search for products in the catalog',
  parameters: {
    query: { type: 'string', required: true, description: 'Search query' },
    maxPrice: { type: 'number', description: 'Maximum price filter' }
  },
  handler: async ({ query, maxPrice }) => {
    const results = await yourAPI.searchProducts(query, { maxPrice })
    return { count: results.length, products: results }
  }
})
```

That's it. When a user with athreei visits your site, their AI can now search your products.

## Two APIs

### Simple API (Recommended)

A singleton for quick integration:

```typescript
import { athreei } from '@athreei/sdk'

athreei.onReady((info) => { /* ... */ })
athreei.registerTool({ /* ... */ })
```

### Class-based API

For more control:

```typescript
import { AthreeiClient } from '@athreei/sdk'

const client = new AthreeiClient({ debug: true })
await client.waitForReady()
client.registerTool({ /* ... */ })
client.destroy() // Clean up
```

## What Can You Expose?

### E-commerce

```typescript
athreei.registerTool({
  name: 'add_to_cart',
  description: 'Add a product to the shopping cart',
  parameters: {
    productId: { type: 'string', required: true },
    quantity: { type: 'number', default: 1 }
  },
  handler: async ({ productId, quantity }) => {
    await cart.add(productId, quantity)
    return { success: true, cartTotal: cart.getTotal() }
  }
})
```

### SaaS Applications

```typescript
athreei.registerTool({
  name: 'create_project',
  description: 'Create a new project in the workspace',
  parameters: {
    name: { type: 'string', required: true },
    template: { type: 'string' }
  },
  handler: async ({ name, template }) => {
    const project = await api.createProject({ name, template })
    return { projectId: project.id, url: project.url }
  }
})
```

### Content Platforms

```typescript
athreei.registerTool({
  name: 'search_articles',
  description: 'Search articles by topic',
  parameters: {
    topic: { type: 'string', required: true },
    limit: { type: 'number', default: 10 }
  },
  handler: async ({ topic, limit }) => {
    const articles = await search(topic, { limit })
    return { articles }
  }
})
```

## Controlling AI Actions

### Observe Actions

Monitor what AI does on your site:

```typescript
athreei.onBeforeAction((action) => {
  analytics.track('ai_action', { tool: action.tool })

  // Return false to cancel the action
  if (action.tool === 'browser_navigate' && !isAllowedUrl(action.args.url)) {
    return false
  }
})

athreei.onAfterAction((result) => {
  console.log('Action completed:', result.tool, result.success)
})
```

### Request Permissions

Ask users for explicit permission:

```typescript
const granted = await athreei.requestPermission({
  scopes: ['interact', 'read'],
  reason: 'To help you complete your order',
  duration: 'session'
})
```
