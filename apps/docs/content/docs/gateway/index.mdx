# Gateway

The athreei Gateway is the core of the platform: **connect one MCP to your AI app, access any MCP server through it**.

## Why Use a Gateway?

Today, connecting AI apps to MCP servers is painful:
- Each MCP server requires separate configuration
- Claude Desktop supports multiple servers, but other apps may not
- No visibility into what tools are being called
- No centralized management

athreei solves this with a gateway:

```
┌─────────────────┐     ┌─────────────────────────────────────────────────┐
│     AI App      │     │              athreei Gateway                    │
│  (Claude, GPT)  │     │                                                 │
│       │         │     │  ┌───────────────┐  ┌───────────────┐           │
│       ▼         │     │  │  GitHub MCP   │  │ Filesystem MCP│           │
│  ┌─────────┐    │     │  │  (5 tools)    │  │   (3 tools)   │           │
│  │ athreei │────┼────►│  └───────────────┘  └───────────────┘           │
│  └─────────┘    │     │                                                 │
│                 │     │  ┌───────────────┐  ┌───────────────┐           │
└─────────────────┘     │  │   Slack MCP   │  │  Custom MCP   │           │
                        │  │  (4 tools)    │  │  (N tools)    │           │
                        │  └───────────────┘  └───────────────┘           │
                        │                                                 │
                        │  ──────────────────────────────────────────     │
                        │                 Audit Logs                      │
                        │           (every call logged)                   │
                        └─────────────────────────────────────────────────┘
```

## Key Features

### One Connection, Many Servers

Configure athreei once in your AI app:

```json
{
  "mcpServers": {
    "athreei": {
      "command": "athreei-gateway"
    }
  }
}
```

All your MCP servers (configured via Platform) are accessible through this single connection.

### Automatic Tool Namespacing

Tools from different servers are prefixed to prevent collisions:

| Server | Original Tool | Aggregated Name |
|--------|---------------|-----------------|
| github | `create_issue` | `github__create_issue` |
| filesystem | `read_file` | `filesystem__read_file` |
| slack | `send_message` | `slack__send_message` |

### Built-in Audit Logging

Every tool call through the gateway is logged:
- Tool name and server
- Request parameters
- Response data
- Status and duration

[Learn more about Audit Logs →](/docs/audit-logs)

## Gateway Configuration

Create `~/.athreei/config.json` with your Platform credentials:

```json
{
  "apiKey": "ak_your_api_key_here",
  "endpoint": "your-endpoint-name"
}
```

MCP servers are configured via the [Platform dashboard](https://athreei.com), not in the local config file.

## Gateway Types

### Local Gateway

A standalone binary that runs on your machine:

```bash
# Download and run
athreei-gateway
```

**Best for:**
- Users who want everything local
- Combining multiple local MCP servers
- Maximum control over configuration

[Local Gateway Setup →](/docs/gateway/local)

### Cloud Gateway

A hosted service with SSE transport:

```javascript
const response = await fetch('https://gateway.athreei.com/sse', {
  headers: { 'Authorization': 'Bearer YOUR_TOKEN' }
})
```

**Best for:**
- Web-based AI applications
- Teams wanting centralized management
- Environments where local binaries aren't practical

[Cloud Gateway Setup →](/docs/gateway/cloud)

## Comparison

| Feature | Local Gateway | Cloud Gateway |
|---------|--------------|---------------|
| Transport | stdio | SSE |
| Data location | Your machine | Encrypted on server |
| Setup | Download binary | API endpoint |
| Server config | Platform dashboard | Platform dashboard |
| Audit logs | Platform sync | Platform sync |
